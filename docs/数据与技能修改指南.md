## 权威数据入口

| 修改内容 | 文件 |
| --- | --- |
| 玩家精灵属性、职业、默认站位 | `src/data.ts` 的 `SPIRITS` |
| 玩家技能威力、消耗、回复和 CD | `src/data.ts` 的 `SKILLS` |
| 团队妖力初始值与上限 | `src/data.ts` |

| 怪物、技能、Boss 与随机池 | `src/monsterData.ts` |
| 怪物行为选择与 Seed | `src/monsterSystem.ts` |
| 玩家技能和回合结算 | `src/battle.ts` |
| 通用回合、状态与目标规则 | `src/coreBattleRules.ts` |
| 副本内容 | `src/stages.ts` |

`src/monsterData.ts` 是当前正式怪物数据入口，旧怪物导入数据不再进入运行代码。

## 玩家精灵常用字段

```ts
{
  id: 'P01',
  name: '炽刃狐',
  role: '攻击×攻击',
  maxHp: 262,
  physicalAttack: 133,
  physicalDefense: 84,
  magicAttack: 80,
  magicDefense: 88,
  speed: 130,
  skillIds: ['M01-S1', 'M01-S2', 'M01-S3'],
  defaultPosition: 'back'
}
```

`speed` 是回合开始生成行动顺序时读取的速度。`defaultPosition` 只能使用 `front` 或 `back`。

## 玩家技能常用字段

| 字段 | 作用 |
| --- | --- |
| `power` | 技能威力 |
| `cost` | 固定消耗妖力 |
| `gain` | 固定获得妖力 |
| `cooldown` | 技能冷却 |
| `hitCount` | 固定攻击段数 |
| `costAllMana` | 消耗当前全部妖力 |
| `gainCap` | 妖力回复后的上限 |
| `healPercent` | 回复目标最大生命比例 |
| `healSelfAndTargetPercent` | 同时回复施法者与所选目标最大生命比例；目标为自身时只结算一次 |
| `selfHealPercent` | 攻击后回复自身最大生命比例 |
| `frontHealPercent` | 回复存活前排最大生命比例 |
| `teamHealPercent` | 回复场上全体各自最大生命比例 |
| `healFlatValue` | 固定数值治疗 |
| `shieldValue` / `teamShieldValue` | 单体 / 场上全体获得固定护盾 |
| `shieldToFixedDamageRatio` | 消耗护盾并转换为固定伤害 |
| `addDamageAmpStacks` | 获得爆发层数 |
| `addChargeTurns` / `addRegenTurns` | 施加蓄势 / 回复 |
| `addShieldFormationTurns` | 施加盾阵 |
| `addBossVulnerabilityTurns` | 对 Boss 施加易伤 |
| `consecutiveUseCostReduction` | 连续使用时逐次减费 |
| `firstUseInBattleCostReduction` | 本场第一次使用减费 |
| `firstSkillAfterEntryCostReduction` | 每次入场后的第一次技能减费 |

技能回能没有每回合额度，`gain` 只受团队妖力上限 10 约束。

新增字段前先检查 `SkillData`、`BattleGame.resolveSkill` 和 UI 的技能描述，避免只改数据显示而没有结算。

## 怪物与 Boss 修改流程

1. 在 `src/monsterData.ts` 修改怪物定义、技能或随机池。
2. 在 `src/stages.ts` 修改固定五场阵容或随机生成约束。
3. 检查法师成长是否仍使用 `increase_runtime_skill_power`，不得改成状态。
4. 运行测试与构建。

敌人的相对权重、强制开局、强制后继、预告和运行时威力由怪物配置与 `src/monsterSystem.ts` 共同解释。
