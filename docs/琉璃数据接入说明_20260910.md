# 琉璃数据接入说明

**版本号：** v1.0  
**修改日期：** 2026-09-10

## 数据来源与优先级

本次正式配置依据以下机器可读表接入：

1. `琉璃Demo_十六精灵设计表_v2.3_六精灵定位属性命名冻结_20260824.xlsx`
2. `琉璃Demo_怪物配置表_v1.6_机器可读AI版_20260902.xlsx`

上述表格覆盖旧十精灵数据及第一章怪物、技能和编队；未被新表覆盖的通用战斗规则与旧副本继续沿用原工程规则。

## 已接入内容

- `src/data.ts`：16 只精灵、48 个技能、定位、元素、站位与冻结属性。
- `src/monsterData.ts`：堆堆石、灯笼怪、小熊妖、白衣秀士、凌虚子及 10 个怪物技能。
- `src/monsterSystem.ts`：怪物种族值成长公式、固定技能序列和可配置起始序号。
- `src/stages.ts`：琉璃第一章 8 场固定连战，包含第三场灯笼怪错峰技能序列及最终双首领编队。
- `src/battle.ts`：概念组爆发一次性消耗、护盾延续、护盾行动周期延长、最低生命友军治疗等新机制。
- UI：显示精灵/怪物元素、新前排位置及新增状态。

## 实现边界与待确认项

- 表格提供了元素字段，但未提供元素克制或伤害倍率规则；当前只展示和保存元素，不擅自加入克制计算。
- 第四场只标注两只小熊妖速度轻微错开，第五场只标注“小熊妖 A 高速、小熊妖 B 初始受伤”，均没有给出具体修正值。当前保留标准速度与满生命，并在关卡配置中记录待确认说明。
- P11 至 P16 使用表内“概念组”爆发规则：全部层数作用于下一次攻击并一次性消耗，非攻击行动不消耗；P01 至 P10 继续使用旧组规则。

## 验收标准

- 16 只精灵及 48 个技能可被战前选择和战斗系统读取。
- 5 种新怪物按 10 级公式得到表内最终属性，并按技能序列行动。
- 琉璃第一章可选择并加载全部 8 场编队。
- `npm test` 与 `npm run build` 均通过。
