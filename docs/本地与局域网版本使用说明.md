# 本地与局域网版本使用说明

## 版本隔离

- 本地开发版读取源码并使用热更新，地址为 `http://127.0.0.1:5173/`。
- 局域网版本读取独立静态快照 `dist-lan/`，地址为 `http://本机局域网IP:5174/`。
- 修改源码、运行测试或执行普通 `npm run build` 都不会改变 `dist-lan/`。
- 只有执行 `npm run lan:sync`，或明确要求 Codex“同步到局域网版本”，才会生成新的局域网快照。

## 日常操作

### 启动本地开发版

双击 `启动本地开发版.bat`，或执行：

```powershell
npm.cmd run dev:local
```

### 启动局域网版本

双击 `启动局域网版本.bat`，或执行：

```powershell
npm.cmd run lan:serve
```

### 同步到局域网版本

双击 `同步到局域网版本.bat`，或执行：

```powershell
npm.cmd run lan:sync
```

同步不会强制刷新伙伴已经打开的战斗页面。伙伴完成当前战斗并主动刷新后，才会载入新版本。

## 协作约定

后续普通代码修改默认只进入本地开发版。只有收到“同步到局域网版本”的明确指令后，才更新 `dist-lan/` 并验证局域网入口。
