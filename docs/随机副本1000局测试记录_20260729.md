# 琉璃 Demo｜随机副本 1000 局测试记录

- 版本：本地开发版（2026-07-29）
- 样本数：1000 个完整随机副本
- 固定 Seed 基准：`2026072701`
- Seed 公式：`seedBase + (index + 1) * 7919 (uint32)`
- 测试策略：当前自动策略 AI，随机一键战斗阵容
- 测试范围：5 场连续随机副本，保留当前阵容、生命、阵亡与团队妖力

## 一、结论

1. 1000 局中通关 259 局，总通关率为 **25.90%**，没有运行异常、卡死、非法生命或非法妖力。
2. 难度主要集中在第 4、5 场：第 4 场到达后通关率 73.35%，第 5 场到达后通关率 38.89%。
3. 团队妖力确实形成资源压力：行动开始时平均妖力 2.0737，19.34% 的行动从 0 妖力开始，妖力溢出率仅 0.32%。
4. 四类主要行为均被自动策略实际使用，但分布不均：攻击 42.51%、恢复 28.15%、回能 16.00%、防护 13.34%。
5. 局部技能选择存在明显收敛：铁甲犀【蓄能冲撞】占自身技能行动 94.62%；逐风隼【风切】和铁甲犀【铁甲盾阵】使用次数为 0。
6. 这些结果只能代表当前自动策略，不等同于真人最优策略。尤其持续防护、铺垫和延迟收益技能可能被策略评分低估。

## 十一、当前不能直接下结论的内容

1. 不能仅凭随机队伍关联通关率认定单只精灵过强或过弱。
2. 不能仅凭 0 次使用认定技能无效，需要先确认自动策略是否正确估价其延迟收益。
3. 不能以 25.90% 总通关率直接判断难度合适，尚缺少目标玩家、期望通关率与真人操作样本。
4. 当前结果可以确认系统运行稳定、妖力有压力、阶段难度有分层，也可以定位需要固定对照验证的技能与精灵。
