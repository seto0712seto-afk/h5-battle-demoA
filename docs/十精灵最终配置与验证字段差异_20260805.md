# 十精灵最终配置与验证字段差异

**版本：** 2026-08-05  
**适用范围：** 当前系统1十精灵技能与技能量化验证  
**代码基线：** `project-main`

## 1. 本轮确认边界

1. 团队妖力初始值保留当前规则：0；上限10。
2. 爆发保留当前结算：当前全部层数参与本次技能，持有者正常行动结束后清除；未改为每次技能只消耗1层。
3. 额外行动不获得行动开始妖力，也不获得技能妖力；被抑制的技能回能仍记录为“请求值”，实际获得为0。
4. 护盾来源采用FIFO台账归因，但台账只影响记录，不改变总护盾、吸收伤害或技能消耗护盾的既有结算。

## 3. 数据字段变化

### 复用字段

- 回合、行动者、技能、目标、技能确认时妖力、实际费用。
- 伤害请求值/实际值/护盾吸收，治疗请求值/有效值/过量值。
- 护盾生成、妖力请求/获得/消耗、换宠、阵亡、Boss行为和战斗结果。

### 本次新增字段

- 技能链路：`battleId`、`actionId`、`skillCastId`、配置费用、行动开始前后妖力、技能结算后妖力、免费原因。
- 动态技能状态：入场序号、入场后技能序号、战斗内使用次数、连续使用次数、释放前后状态、重置原因。
- 伤害分段：命中序号、伤害类型、修正前伤害、最终伤害、暴击信息、结算前后HP。
- 易伤归因：状态实例、来源精灵/技能、无易伤伤害、易伤额外伤害。
- 护盾归因：护盾实例、来源精灵/技能、生成量、FIFO吸收量、主动消耗量及生成的固定伤害。
- 状态归因：爆发、蓄势、回复、盾阵、易伤的实例、来源、层数变化、持续时间变化和移除原因。

统一事件协议新增兼容映射：`skill_resolve`、`shield_consume`、实例级`shield_absorb`、`status_apply/status_remove`。旧事件仍可继续解析。

## 4. 新增派生统计

- 每技能使用占比、重复率、平均配置/实际费用、免费率、平均伤害、平均有效治疗、过量治疗、护盾利用率、技能回能及溢出。
- 炽能连斩费用档、完整循环和两种重置原因。
- 爆发来源、兑现层数、风暴突袭必暴及未兑现层数。
- 回复完整兑现、提前移除和损失回合。
- 盾压护盾来源构成、消耗量、固定伤害及岩壁守护衔接率。
- 铁壁援护条件治疗率、有效治疗和护盾利用率。
- 灵铃庇佑免费资格、免费/付费治疗与护盾利用率。
- 易伤覆盖回合、覆盖命中、基础伤害、额外伤害和未利用窗口。
- 三个技能回能贡献、星能回流免费/付费与回合分布、星甲冲击技能占比与护盾利用率。
